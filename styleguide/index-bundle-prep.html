03 · Logos

One mark. One wordmark. One lockup pattern.

The mark ships as a single PNG; theme handles dark/light by swapping which file is rendered. The full lockup is a recipe — mark + Montserrat WRLD + uppercase sub-label. Sub-brand variants (Tech, Host, Design, AI, Services…) are built by changing the sub-label only. The tab icon is the same 18-ray starburst on #0a0a0a — assets/logos/favicons/favicon.svg — never a circle, disc, or gear.
