# WRLD.AI — Product / Dashboard UI Kit

Tailored AI agents for SMB operations. Dashboard surfaces, agent details, run history.

**Tone dial:** warmth high · formality medium · technicality low–med · urgency medium.
**Accent weighting:** WRLD.AI uses `#00ADEE` (signal/intelligence) as the preferred hover/focus accent — distinguishes it from flagship blue. `#EE9300` only on subscription/upgrade CTAs.

## Files

- `index.html` — clickable agent dashboard. Sidebar + agent list + agent detail with run history.
- `Sidebar.jsx`, `AgentList.jsx`, `AgentDetail.jsx`, `RunHistory.jsx`, `StatCard.jsx`, `TopBar.jsx`.

## Design notes

- Monochrome surfaces. Status pills use system semantic green/amber/red.
- Sparse iconography (Lucide CDN, 1.5px stroke).
- Agent cards have a hairline border and 8px radius — accent-tinted shadow on hover.
