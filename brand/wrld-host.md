# wrld.host — Hosting Platform Brief

> Load `brand/CLAUDE.md` first.

**Property.** wrld.host — cPanel/WHM hosting, domains, SSL, dedicated servers, VoIP (Telzio partnership), managed DNS.
**Audience.** Web developers, agencies, WRLD clients needing hosting, WordPress power users. Primarily technical.
**Relationship to flagship.** Service branch. Shares voice and values. Tone dial tilts more technical and efficiency-focused.

## Tone dial

Warmth **Medium** · Formality **Low-Med** · Technicality **Medium-High** · Urgency **Medium**.

Platform-native language. Speak to developers like peers. Specs matter.

## Color weighting

Monochromatic base. Hover accent uses `#00adee` (secondary) by default — a slightly cooler, more "technical" feel than flagship `#007fee`. Commerce elements (upgrade, renew, add domain) still use `#EE9300`. Dashboard UI stays fully monochromatic; accents appear on hover/focus only.

## Positioning

> "Hosting chosen deliberately. The WRLD.host platform is a clustered, ethically-operated hosting environment reserved for WRLD clients and approved partners — fast by default, no noisy neighbors, real humans answering tickets."

## Must-haves

- Technical specs front-and-center (RAM, storage, bandwidth, uptime SLA).
- Clear differentiation from big-box hosts: "No sub-channel resellers. No predatory upsells. Direct platform access."
- Links to portal/client area: `portal.wrld.tech`.
- VoIP callouts reference **Telzio** partnership by name when appropriate (ethically-aligned vendor).

## Avoid

- "Unlimited" anything without asterisks.
- Scarcity / FOMO sales copy.
- Enterprise jargon where plain English ("always-on") works.
- Comparing against GoDaddy / Bluehost by name — lead with WRLD's philosophy instead.
