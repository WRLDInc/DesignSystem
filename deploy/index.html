How it is built

Modern minimalist. Monochrome. Accents only when something moves.

Static surfaces stay grayscale — #0a0a0a as ink in light mode, #fafafa as paper in dark. The three accents appear on hover, focus and motion, never as decoration. Geometry beats illustration; whitespace beats ornament.

The system is the same code our clients ship on: tokens compiled straight from WRLDInc/DesignSystem, fonts we host ourselves, components rendered live in both themes. It is published here because we would rather show our work than describe it.
