WRLD Design

WRLD design system

One source of truth for every WRLD surface.

Tokens, typefaces, logos, brand briefs, and per-product UI kits. Modern minimalist, monochromatic in light and dark, with accents reserved for interaction — never decoration. Everything here is served straight from the WRLDInc/DesignSystem repository, so the site and the source never drift.

Consume the system

Link one stylesheet and you have the full foundation: the token suite, the four self-hosted typefaces, and semantic element styles. Light and dark are driven by data-theme on the root element — light, dark, or auto to follow the operating system. 

<!-- everything: tokens + fonts + element styles -->
<link rel="stylesheet" href="https://wrld.design/styles.css">

<!-- or just the token layer -->
<link rel="stylesheet" href="https://wrld.design/tokens/tokens.css">

<html data-theme="auto">
PathWhat it is
/styles.cssEntry point. Imports the token suite, then the type and color foundation.
/tokens/tokens.cssFull token suite as --wrld-* custom properties, light and dark.
/tokens/tokens.jsonThe same tokens as data, for tooling and design-tool sync.
/tokens/tokens.tsTyped token exports for TypeScript consumers.
/colors_and_type.cssStandalone color and type foundation, including the @font-face set.
/registry/theme/wrld.cssThe same tokens as a shadcn / Tailwind v4 theme (:root + .dark), generated from the token suite. Paste into globals.css.
/registry/manifest.jsonWhat the 21st.dev team library serves — component names, slugs, descriptions and stable refs.
/fonts/Self-hosted Ubuntu, Ubuntu Mono, and Montserrat — for example Ubuntu-Regular.ttf. Never load these from a font CDN.
/assets/logos/Authentic mark and lockup artwork (PNG) — for example wrld-mark-black.png.
/logos/favicons/Complete favicon and web-manifest set, including site.webmanifest.
