One system behind every WRLD surface.

Modern minimalist. Dark/light monochromatic. Accents are interactive, never decorative. This is the living source of truth for WRLD's tokens, typography, logos, components, and brand voice — the same meticulous system we run for client work.

Principles

Continuity is a discipline, not an accident.

Every rule below is enforced in tokens, linted in CI, and readable by both humans and machines.

Monochromatic base

Every static surface lives on a twelve-step neutral scale, from white to the signature near-black #0a0a0a. No decorative color, ever.

Accents are interactive

WRLD blue #007fee, sky #00adee, and warm #EE9300 appear only on hover, focus, motion, and gradients — never as static fills.

Tokens before pixels

Color, type, spacing, radii, shadows, and motion ship as CSS custom properties, JSON, and TypeScript — one source of truth, three consumption formats.

Machine-readable by design

Briefs are markdown, tokens are JSON, adherence is lintable. Any agent or LLM can be pointed here and produce unmistakably-WRLD output.
